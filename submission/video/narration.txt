This is Hex Machina. It is a debugger for executable graphs, and a browser agent is about to drive it through seven WebMCP tools.

The page registers those tools on document dot modelContext. Everything you are about to see is the agent calling them. Nobody is clicking.

First it inspects the live graph, then it casts the spell. The spell is supposed to water a moonflower. Instead, twelve summoned ducks flood the observatory.

Now it traces the effect. This is a bounded graph traversal, not a guess: it returns the ordered causal path and every edge responsible for it.

Then it proves the diagnosis. The explanation returns the smallest responsible subgraph, and a counterfactual check showing each of those edges is necessary.

Here is the part that matters. A human says something the graph cannot infer: the ducks are funny, they stay. That becomes an executable constraint.

Watch what it changes. The cheapest repair deletes the duck branch entirely. With the constraint locked, that repair is no longer eligible, so the agent ranks a longer one instead.

Before anything is applied, the human sees the exact operation ledger the agent received. Eight graph edits, what is preserved, and what the repair gives up.

The patch is simulated first, without touching editor state. Then applied atomically, with preconditions revalidated at the moment of the write.

The recast succeeds. All twelve ducks survive, they carry umbrellas, the room stays dry, and the moonflower blooms. The human's preference changed the solution, not just the score.

One more thing, because a polished demo invites one question: is this on rails.

The evaluation layer generates ninety six tasks across three different causal rules. Let me load a held out one, from a rule this run has never seen.

Every rune, edge and effect identifier is freshly remapped. Nothing here was memorised. The same seven tools inspect it, cast it, trace it, and explain it.

That is the claim. Graph interfaces let people and agents negotiate executable intent, and the application proves every mutation.
